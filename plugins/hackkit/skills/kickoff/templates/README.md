## Быстрый запуск (Docker)

Требования: Docker 24+ с Compose v2. Ключ LLM и файл `.env` не нужны: у всех переменных есть значения по умолчанию, а по умолчанию работает детерминированный режим `LLM_PROVIDER=fake`.

```bash
git clone {{REPO_URL}} && cd {{REPO_DIR}}
docker compose up --build      # или make up — дождётся healthcheck всех сервисов
```

Открыть http://localhost:5173 (API — http://localhost:8080, `GET /healthz` → 200). Остановить: `make down`.

### Режим с реальной LLM

| Параметр | Значение |
|---|---|
| Сервис | Anthropic Claude API |
| Модель | `LLM_MODEL` (по умолчанию `claude-opus-5`) |
| Переменная ключа | `ANTHROPIC_API_KEY` |
| Подключение | `cp .env.example .env`, в `.env`: `LLM_PROVIDER=anthropic`, `ANTHROPIC_API_KEY=<ключ>` → `docker compose up --build` |
