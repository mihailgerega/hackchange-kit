# Статус команды

Одна строка на обновление, новые сверху. Каждая сессия (человек или Claude) пишет только в свой раздел журнала и читает чужие перед началом задачи.

## Владение (кто что правит)

| Путь | Владелец | Примечание |
|---|---|---|
| `api/openapi.yaml` | общий — меняем только по договорённости | контракт фронт ↔ бэк |
| `backend/internal/agent/**` | {{OWNER_A}} | цикл агента, промпты |
| `backend/internal/services/**` | {{OWNER_B}} | MCP-имитации сервисов |
| `frontend/**` | {{OWNER_C}} | UI |
| `openspec/**`, `docs/**` | {{OWNER_D}} | спеки, архитектура, презентация |
